## Root Cause Analysis

### Why is HC misunderstanding "the right guy"?

This is likely an **LLM comprehension issue**, not a prompt issue. Llama 3.1 might have:
1. Misread "the right guy" as "the right guy [at work]" due to prior context about work
2. Made an inference error

**Possible fixes:**
- Test with a different model (GPT-4o-mini might handle this better)
- Add instruction: "Pay close attention to what the user says literally. Don't make assumptions."

### Why so many questions?

The current rubric says:
> "Acknowledge what they shared, then ask a thoughtful question or suggest one simple next step."

HC is interpreting this as "ask multiple questions" instead of "ask **one** question."

**Fix:** Make it explicit - "ask ONE question" not "questions"

### Why "Next step:" labels?

This might be coming from the original "orchestrator" framing. Even though we removed "orchestrate" from the prompt, the model might still be acting formal.

**Fix:** Add explicit instruction to avoid formal business language.
