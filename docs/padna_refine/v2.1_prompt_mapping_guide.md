# PaDNA v2.1 Prompt Mapping Enhancement Guide

**Purpose:** Address rendering gaps by improving trait-to-prompt conversion with priority weighting and enhanced descriptors.

**Target File:** `web/src/server/trait-to-prompt.ts`

---

## Problem Analysis

Current rendering gaps indicate that certain high-value containers are **under-emphasized** in prompt generation:

1. **Freckles** — Containers exist but aren't rendering (airbrushed skin)
2. **Iris Detail** — Monotone iris lacking flecks/pattern/limbal ring
3. **Skin Texture** — Over-smoothed, missing pores/natural texture
4. **Makeup Detail** — Smoky-eye not dramatic enough, lip finish missing

Root cause: All traits currently treated with equal weight. Need **priority tiers** for critical realism markers.

---

## Enhanced Descriptor Mapping

### 1. Freckles (HIGH-PRIORITY)

**Current Mapping:**
```typescript
'PaDNA.SkinDNA.Freckles.Density': `${valueStr} freckle density`,
'PaDNA.SkinDNA.Freckles.Coverage': `freckles across ${valueStr.replace(/-/g, ' ')}`,
```

**Problem:** Too generic, models ignore or minimize.

**Enhanced Mapping:**
```typescript
// Freckles - ENHANCED with explicit modifiers
'PaDNA.SkinDNA.Freckles.Density': (value) => {
  const densityMap = {
    'none': null,
    'light': 'light scattered freckles',
    'medium': 'noticeable freckles, medium density',
    'heavy': 'heavy freckles, prominent across face',
    'very-heavy': 'very heavy freckles, dense coverage, highly visible'
  };
  return densityMap[value] || `${value} freckle density`;
},

'PaDNA.SkinDNA.Freckles.Coverage': (value) => {
  const coverageMap = {
    'cheeks-only': 'freckles concentrated on cheeks',
    't-zone': 'freckles across nose bridge and t-zone',
    'full-face': 'freckles covering entire face',
    'face-shoulders': 'freckles across face, neck, and shoulders',
    'face-neck-shoulders': 'extensive freckles across face, neck, and shoulders',
  };
  return coverageMap[value] || `freckles across ${value.replace(/-/g, ' ')}`;
},

'PaDNA.SkinDNA.Freckles.Contrast': (value) => {
  const contrastMap = {
    'subtle': 'faint, subtle freckles',
    'visible': 'visible freckles',
    'prominent': 'prominent, well-defined freckles',
    'stark': 'stark, high-contrast freckles'
  };
  return contrastMap[value] || `${value} freckle contrast`;
},
```

**Composite Strategy:**
When multiple freckle containers present, combine into single emphatic descriptor:
```typescript
// Example: medium density + face-shoulders + prominent
// Output: "prominent freckles with medium density across face, neck, and shoulders"
```

### 2. Iris Detail (HIGH-PRIORITY)

**Current Mapping:**
```typescript
'PaDNA.EyeDNA.Iris.BaseColor': `${valueStr} iris`,
'PaDNA.EyeDNA.Iris.Flecks': `iris with ${valueStr} flecks`,
'PaDNA.EyeDNA.Iris.LimbalRing': `${valueStr} limbal ring`,
```

**Problem:** Atomic tokens don't combine well; models default to monotone.

**Enhanced Mapping:**
```typescript
// Iris - ENHANCED with composite descriptors
'PaDNA.EyeDNA.Iris.BaseColor': (value) => {
  // Base color is foundation; emphasize if unique
  const colorEmphasis = {
    'light-green': 'striking light green eyes',
    'light-blue': 'bright light blue eyes',
    'amber': 'warm amber eyes',
    'gray': 'cool gray eyes',
    'hazel': 'hazel eyes'
  };
  return colorEmphasis[value] || `${value.replace(/-/g, ' ')} eyes`;
},

'PaDNA.EyeDNA.Iris.Flecks': (value) => {
  if (value === 'none') return null;
  return `with ${value} flecks in iris`;
},

'PaDNA.EyeDNA.Iris.FleckPattern': (value) => {
  if (value === 'none') return null;
  const patternMap = {
    'scattered': 'scattered throughout iris',
    'central': 'concentrated near pupil',
    'radial': 'radiating outward from pupil',
    'dense': 'densely distributed across iris'
  };
  return patternMap[value] || value;
},

'PaDNA.EyeDNA.Iris.LimbalRing': (value) => {
  if (value === 'none') return null;
  const ringMap = {
    'faint': 'subtle limbal ring',
    'moderate': 'moderate limbal ring adding depth',
    'prominent': 'prominent limbal ring',
    'dark-prominent': 'dark prominent limbal ring for striking eyes'
  };
  return ringMap[value] || `${value} limbal ring`;
},
```

**Composite Strategy:**
Combine iris components into single complex descriptor:
```typescript
// Example: light-green + hazel flecks + scattered + moderate limbal ring
// Output: "striking light green eyes with hazel flecks scattered throughout iris, moderate limbal ring adding depth"
```
