### 2. Prompt Mapping Enhancements ✅

**File**: [web/src/server/trait-to-prompt.ts](../../web/src/server/trait-to-prompt.ts)

#### A. Priority Weighting System

**Implementation**: Added `PRIORITY_WEIGHTS` constant for critical realism containers.

```typescript
const PRIORITY_WEIGHTS: Record<string, 'high' | 'med' | 'std'> = {
  // HIGH priority (2.0× weight)
  'PaDNA.SkinDNA.Texture': 'high',
  'PaDNA.SkinDNA.Freckles.Density': 'high',
  'PaDNA.EyeDNA.Iris.BaseColor': 'high',
  'PaDNA.EyeDNA.Iris.Flecks': 'high',
  'PaDNA.EyeDNA.Iris.Pattern': 'high',
  'PaDNA.EyeDNA.Iris.LimbalRing': 'high',

  // MEDIUM-HIGH priority (1.5× weight)
  'MakeupDNA.Eyes.Style': 'med',
  'MakeupDNA.Lips.Finish': 'med',
  'PaDNA.SkinDNA.Freckles.Distribution': 'med',
  'PaDNA.SkinDNA.Freckles.Prominence': 'med',
};
```

**Usage**: Prompts with `high` priority get 2.0× emphasis, `med` get 1.5×, others 1.0×.

#### C. Anti-Airbrushing Negative Prompt

**Implementation**: Enhanced `getDefaultNegativePrompt()` to add anti-airbrushing terms when natural texture is specified.

```typescript
export function getDefaultNegativePrompt(traits?: TraitDict): string {
  let negativePrompt = 'blurry, low quality, distorted features, ...';

  if (traits) {
    const skinTexture = traits['PaDNA.SkinDNA.Texture']?.resolved_value;
    if (skinTexture === 'natural-with-visible-pores') {
      negativePrompt += ', NOT airbrushed, NOT overly smooth skin, NOT plastic-looking';
    }
  }

  return negativePrompt;
}
```

**Effect**: Prevents LLM from over-smoothing skin when natural texture is specified.

### 3. Root Cause Analysis (From ChatGPT Feedback)

**Problem**: Latest portrait rendering showed:
- Freckles absent/airbrushed
- Iris monotone (lacking flecks/pattern)
- Skin over-smoothed
- Makeup too subtle

**Root Cause**: NOT missing containers, but **insufficient prompt weighting**.

**Solution**:
1. ✅ Priority weighting (HIGH, MEDIUM-HIGH, STANDARD)
2. ✅ Composite descriptors for iris (4 components → 1 phrase)
3. ✅ Composite descriptors for freckles (3 components → 1 phrase)
4. ✅ Anti-airbrushing negative prompts
5. ✅ Enhanced makeup descriptors
