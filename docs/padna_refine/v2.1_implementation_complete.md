---

### 2. Priority Weighting

Traits now sorted by `priority × UCN` before prompt generation:

**HIGH-PRIORITY (weight 2.0):**
- Skin texture, freckles (density/coverage/contrast)
- Iris (base/flecks/pattern/ring)

**MEDIUM-HIGH (weight 1.5):**
- Makeup eyes, makeup lips finish

**STANDARD (weight 1.0):**
- All other containers

**Effect:** High-priority containers with UCN 900 now ranked above standard containers with UCN 950, ensuring critical realism markers appear first.

## Troubleshooting

**Freckles still not visible?**
- Check: `PaDNA.SkinDNA.Freckles.Density` UCN ≥ 920
- Check: Prompt includes "prominent medium density freckles"
- Try: Increase UCN to 950, add explicit "heavy freckles" if needed

**Iris still monotone?**
- Check: All 4 iris components (BaseColor, Flecks, Pattern, Ring) present
- Check: Prompt shows composite descriptor (not individual parts)
- Try: Increase iris component UCNs to 940+

**Skin still airbrushed?**
- Check: `PaDNA.SkinDNA.Texture = "natural-with-visible-pores"`
- Check: Negative prompt includes "NOT airbrushed"
- Try: Add "detailed pores, skin imperfections" to positive prompt

**Smoky eye too subtle?**
- Check: `MakeupDNA.Eyes.Style = "heavy-smoky-eye-with-black-liner"`
- Check: Prompt includes "heavy dramatic smoky eye with thick black eyeliner"
- Try: Increase UCN to 950

**Lips matte instead of glossy?**
- Check: `MakeupDNA.Lips.Finish = "gloss"`
- Check: Prompt includes "glossy lips, shiny finish"
- Try: Increase UCN to 920
